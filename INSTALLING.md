# Linux

An `.AppImage` is included.

# Windows

To install (put into the desktop and Start menu) About This PC on Windows, you need to use the included `About This PC.lnk` shortcut. Just place this file whereever you want; whether that's the user desktop, user Start menu folder, system Start menu folder, etcetera.

Do note that the shortcut uses predefined paths that are only available after initialy extracting About This PC to your local `AppData`, so don't worry if you can't run the app or there's no icon at first.
